Mealy Machine (Input-based Output)
S0 → S1 : Insert Card
S1 → S2 : Process Card
S2 → S3 : Correct PIN / Accepted
S2 → S2 : Wrong PIN / Error
S3 → S4 : Select Withdrawal
S4 → S5 : Valid Amount / Dispense
S4 → S4 : Invalid Amount / Error
S5 → S6 : Transaction Complete
S3 → S8 : Select Balance Inquiry
S7/S8 → S3 : Return to Menu
S2 → S9 : PIN Limit / Retain Card
Active State → S6 : Eject Card
S6/S9 → S0 : Ready for Next Card
S8 → S7 : Confirm / Charge Fee
